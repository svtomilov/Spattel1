# Телеграм-бот Spattel — настройка

Код бота: [site/api/telegram.js](site/api/telegram.js). Он живёт рядом с сайтом и выкладывается тем
же `git push`. Отдельного сервера и платных сервисов не нужно.

Этот файл лежит в корне репозитория, а не в `site/`, поэтому в интернет не попадает.

## Что умеет бот

```
ссылка с сайта → /start → приветствие и четыре кнопки с целью обращения
                        → выбрал цель → бот просит имя и телефон
                        → прислал     → карточка заявки падает в рабочую группу
менеджер отвечает на карточку обычным reply → бот доставляет ответ клиенту
```

Отвечать клиенту может **только сам бот** — из личного аккаунта в переписку с ботом не попасть.
Поэтому ответы идут через группу, а не напрямую.

Свободные сообщения, фотографии и планировки тоже долетают в группу.

## Порядок настройки

### 1. Создать бота

В Telegram напишите **@BotFather** → `/newbot`:

- имя (видно в чате): `Spattel`
- username — обязан заканчиваться на `bot`: например `spattel_bot`

BotFather выдаст токен вида `8123456789:AAH...`. **Это пароль от бота.** Не кладите его в код и не
присылайте в переписку.

Там же полезно сразу: `/setdescription`, `/setabouttext`, `/setuserpic` (логотип Spattel),
и `/setcommands` со строкой `start - Начать`.

### 2. Прописать переменные на Vercel

Project `spattel1` → Settings → Environment Variables. Все три — для Production:

| Имя | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | `xpq4P9fBpi1dholf4QQQEHBV2QugLpKS` |
| `TELEGRAM_CHAT_ID` | заполняется на шаге 4 |

После добавления переменных нужен новый деплой, иначе функция их не увидит: Deployments →
последний → Redeploy.

### 3. Подключить вебхук

Один раз, в Терминале. Подставьте свой токен вместо `ТОКЕН`:

```sh
curl -sS "https://api.telegram.org/botТОКЕН/setWebhook" \
  -H 'content-type: application/json' \
  -d '{
    "url": "https://spattel.ru/api/telegram",
    "secret_token": "xpq4P9fBpi1dholf4QQQEHBV2QugLpKS",
    "allowed_updates": ["message", "callback_query"]
  }'
```

В ответ должно прийти `{"ok":true,...,"description":"Webhook was set"}`.

Проверить состояние в любой момент: `curl "https://api.telegram.org/botТОКЕН/getWebhookInfo"`.
Поле `last_error_message` покажет, если что-то отваливается.

### 4. Создать рабочую группу и узнать её id

1. Создайте группу, например «Spattel — заявки».
2. Добавьте туда бота и всех, кто будет отвечать.
3. Напишите в группе `/id` — бот ответит числом вида `-1001234567890`.
4. Впишите это число в `TELEGRAM_CHAT_ID` на Vercel и сделайте Redeploy.

Группа лучше личных сообщений: заявки видит вся команда и ничего не теряется при передаче дел.

### 5. Переключить кнопку на сайте

В [site/index.html](site/index.html) заменить `https://t.me/s_tomilov` на
`https://t.me/ВАШ_БОТ?start=site`.

Хвост `?start=site` не косметика: он приходит в бота, и в группе будет видно, что человек пришёл
с сайта, а не из Авито или с визитки. Для других площадок — `?start=avito`, `?start=vizitka`.

## Чего бот сознательно не делает

- **Не называет цены и сроки.** Вилку считает калькулятор на сайте, у бота своей логики нет, чтобы
  не разошлись две разные цифры.
- **Не обещает время ответа точнее, чем «в рабочее время».** Настоящий регламент не подтверждён.
- **Не спрашивает согласие на обработку персональных данных.** Бот собирает имя и телефон — это те
  же данные, что и форма на сайте, и по 152-ФЗ нужна рабочая политика. Сейчас
  [site/privacy.html](site/privacy.html) — незаполненный шаблон: без даты редакции и без реквизитов
  ООО «ФРИ ХОУМ». Как документ будет готов, в приветствие добавляется строка со ссылкой на него.

## Если что-то пошло не так

| Симптом | Где смотреть |
| --- | --- |
| Бот молчит на `/start` | `getWebhookInfo` → `last_error_message`; логи функции в Vercel → Logs |
| Заявки не приходят в группу | не задан или неверный `TELEGRAM_CHAT_ID`; бота выгнали из группы |
| Ответ менеджера не доходит | отвечать нужно **reply** именно на сообщение бота; клиент мог заблокировать бота |
| `401` в логах | `TELEGRAM_WEBHOOK_SECRET` на Vercel и в `setWebhook` разошлись |

## Что стоит добавить потом

- Согласие на обработку данных — как только появится готовая политика.
- Кнопка «поделиться телефоном» в один тап вместо ввода руками. Сейчас телефон вводится текстом:
  такое сообщение приходит как ответ на вопрос бота, и по нему видно выбранную цель. Сообщение от
  кнопки ответом не является, и связь с целью теряется. Чтобы получить и кнопку, и цель, нужна
  память между сообщениями — то есть хранилище (Vercel KV или подобное).
- Передача заявок в CRM, когда она появится.
